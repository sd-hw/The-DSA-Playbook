# Additional learning resources

Use these as supplements, not as an excuse to keep switching roadmaps.

## Core practice

- [LeetCode](https://leetcode.com/) — practice platform and problem discussions.
- [NeetCode](https://neetcode.io/) — curated roadmap and explanations.
- [CP-Algorithms](https://cp-algorithms.com/) — reference material for algorithms and competitive programming.
- [VisuAlgo](https://visualgo.net/) — visualisations for selected data structures and algorithms.

## Reference and language

- [cppreference](https://en.cppreference.com/w/) — C++ language and standard-library reference.
- [C++ Core Guidelines](https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines) — C++ design and usage guidance.

## How to evaluate a resource

Before adding a resource to your routine, ask:
- Does it explain why, or only show code?
- Is it accurate and maintained?
- Does it match my current level?
- Does it complement my current roadmap?
- Can I apply it immediately to a problem?

Avoid collecting more resources than you can use.

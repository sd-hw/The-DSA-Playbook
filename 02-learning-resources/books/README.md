# Book & Reference Library

This directory explains what each book is useful for and where to study specific topics. It is a **reading guide**, not a mirror of the books.

## Books currently mapped

| Book | Edition in the uploaded copy | Best use |
|---|---|---|
| *Cracking the Coding Interview* — Gayle Laakmann McDowell | 6th edition (2015) | Interview problem-solving process, classic problems, hints and solution reasoning |
| *Data Structures Using C* — Reema Thareja | 2nd edition (2014) | Structured introduction to data structures, operations, implementations and algorithm analysis |

## How to use the library

1. Start with the topic in [The DSA Study Map](../../07-the-dsa-study-map/README.md).
2. Read the recommended section in the relevant book.
3. Attempt selected questions before viewing solutions.
4. Use NeetCode / LeetCode to practise applying the concept in different forms.
5. Record the attempt and schedule revision.

## Edition and language notes

- The uploaded Reema Thareja PDF is **Data Structures Using C, Second Edition (2014)**, published by Oxford University Press. It is not the third edition.
- Reema Thareja's book teaches implementations in C. Use it for conceptual understanding and implementation logic, then practise the corresponding structures and algorithms in C++.
- The uploaded CTCI copy is the **Sixth Edition (2015)**. Some examples and interview context are dated; use it selectively and supplement it with current practice.
- Exact page numbers below refer to the printed page numbers shown in the books, not necessarily the PDF viewer's page counter.

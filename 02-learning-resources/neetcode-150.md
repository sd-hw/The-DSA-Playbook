# NeetCode 150

**Role in this playbook:** structured, pattern-oriented problem-solving practice.

- [Official NeetCode roadmap](https://neetcode.io/roadmap)
- [NeetCode website](https://neetcode.io/)

Use the official roadmap for the current problem list and topic organisation. This repository does not copy problem statements or solutions.

## How to use the roadmap

1. Pick a topic that matches the fundamentals you are studying.
2. Attempt the problem independently before watching an explanation.
3. State a brute-force approach and its complexity.
4. Identify the key observation that enables an improved solution.
5. Implement and test edge cases.
6. Explain why the algorithm is correct.
7. Record your performance and next revision date in the tracker.

## Don't optimise for completion percentage

A completed checkbox is not proof of mastery. For each problem, record whether you:
- solved it independently,
- needed a hint,
- needed to see the approach,
- understood the explanation,
- could re-derive it later.

If a problem was solved only after reading the solution, mark it as a learning attempt and schedule a revision.

## Suggested progression

Follow the current official roadmap's topic order if you need structure. If you already know some topics, take a short diagnostic and focus on weak areas. Do not skip fundamentals simply to reach harder problems faster.

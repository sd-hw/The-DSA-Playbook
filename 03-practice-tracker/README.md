# 03 — Practice tracker

Use `dsa-tracker.csv` to record what happened during a problem attempt, not just whether a green tick appeared.

## Recommended fields

- **Problem:** title or platform link.
- **Topic / pattern:** the main concept tested.
- **Difficulty:** platform label or your own estimate.
- **Attempt date:** date of the attempt.
- **Solved independently?:** yes / partly / no.
- **Hints used:** none / light / substantial / solution viewed.
- **Key takeaway:** the observation or invariant you learned.
- **Weakness:** what you need to improve.
- **Next revision:** date for the next active-recall attempt.
- **Status:** new / learning / revise / strong.

## Suggested revision intervals

Start with 1, 3, 7, 14 and 30 days after learning. These are practical starting intervals, not a scientifically optimal schedule for every learner. Move a problem earlier if you struggle; extend the interval after independent success.

## Tracker discipline

- Record the actual date and outcome.
- Do not mark a problem mastered because you recognised the solution.
- Keep notes short enough that you will revisit them.
- Use a separate row for a meaningful reattempt if you want a history of progress.

# 05 — Revision system

Revision is not optional cleanup after solving problems. It is how you test whether the reasoning has stuck.

> Solving a problem teaches you something. Revisiting it proves you learned it.

## The revision loop

1. Finish a problem and write a one- or two-sentence takeaway.
2. Record what help you needed.
3. Schedule a revisit.
4. Hide your previous code and explanation.
5. Re-derive the approach from the problem statement.
6. Implement or explain it.
7. Update the next revision date based on performance.

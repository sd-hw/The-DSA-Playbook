# Interview problem-solving checklist

## Before coding
- [ ] Restate the problem.
- [ ] Clarify constraints and assumptions.
- [ ] Work through examples.
- [ ] Identify edge cases.
- [ ] Describe a brute-force approach.
- [ ] Explain the optimisation and why it is valid.

## While coding
- [ ] Use clear variable names.
- [ ] Keep functions focused.
- [ ] Explain important decisions.
- [ ] Handle boundaries and empty inputs.
- [ ] Avoid unnecessary complexity.

## After coding
- [ ] Dry-run a normal example.
- [ ] Test edge cases.
- [ ] Analyse time complexity.
- [ ] Analyse auxiliary space.
- [ ] Explain correctness.
- [ ] Discuss trade-offs or alternatives.

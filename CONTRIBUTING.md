# Contributing

Thanks for helping improve The DSA Playbook.

## What is welcome

- Clearer explanations of foundational concepts.
- Corrections to technical inaccuracies.
- Improvements to prompts and revision workflows.
- Additional reputable learning resources.
- Tracker improvements and accessibility fixes.

## Contribution principles

1. Prefer understanding over memorisation.
2. Explain assumptions and trade-offs.
3. Include complexity analysis where relevant.
4. Do not copy book chapters, proprietary problem statements, paid course material or other copyrighted content.
5. Link to original resources and respect their terms.
6. Do not present AI-generated claims as verified facts without checking them.

## Pull request checklist

- [ ] The change is technically accurate.
- [ ] Links work and point to the intended resource.
- [ ] No copyrighted third-party content has been copied.
- [ ] The language is clear and beginner-friendly.
- [ ] Any new prompt has been tested on a real example.

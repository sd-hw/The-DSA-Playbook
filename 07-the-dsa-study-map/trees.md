# Trees and binary search trees

## Learn
- **Reema Thareja, 2nd ed.:** Chapter 9, *Trees*, pp. 279–297; Chapter 10, *Efficient Binary Trees*, pp. 298–343. Topics include binary trees, traversals, BST operations, AVL trees, red-black trees and splay trees.
- **CTCI, 6th ed.:** Chapter 4, *Trees and Graphs*, begins p. 100. Listed topics include types of trees, binary-tree traversal and binary heaps.

## Focus on
Tree terminology, recursive structure, preorder/inorder/postorder/level-order traversal, BST ordering, height, balanced trees and recursion stack space.

## Practise
Use NeetCode Trees. Practise recursive DFS, iterative DFS, BFS/level order, BST validation, lowest common ancestor and tree construction.

## Check your understanding
- What does each traversal visit first?
- Why does inorder traversal of a BST produce sorted order?
- What is the difference between a binary tree and a binary search tree?
- How does tree height affect operation complexity?

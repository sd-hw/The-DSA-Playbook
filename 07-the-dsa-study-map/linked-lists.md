# Linked lists

## Learn
- **Reema Thareja, 2nd ed.:** Chapter 6, *Linked Lists*, printed pp. 162–218. It covers singly, circular, doubly, header and multi-linked lists, along with insertion, deletion and applications.
- **CTCI, 6th ed.:** Chapter 2, *Linked Lists*, begins p. 92. The contents identify creating a linked list, deleting a node, the runner technique and recursive problems.

## Focus on
Node structure, pointer/reference updates, head/tail handling, traversal, insertion/deletion, reversing, fast/slow pointers and cycle detection.

## Practise
Use the linked-list section of the official NeetCode roadmap. Add variations involving reversal, merging, cycle detection and pointer repositioning.

## Check your understanding
- Which references must change when inserting or deleting a node?
- Why does fast/slow pointer cycle detection work?
- What are the edge cases for reversing an empty list or a one-node list?
- What is the difference between O(1) insertion when a node is known and finding that node?

## C++ note
Translate the node and pointer concepts into C++. Be deliberate about ownership and lifetime; the book's C examples do not automatically establish modern C++ best practices.

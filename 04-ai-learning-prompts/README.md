# 04 — AI learning prompts

These prompts are designed to make AI a tutor and reviewer, not a replacement for your own reasoning.

## Available prompts

- [Socratic DSA tutor](socratic-dsa-tutor.md) — learn new problems through progressive hints.
- [DSA revision tutor](dsa-revision-tutor.md) — revisit problems from the context of an existing chat.
- [Mock interviewer](mock-interviewer.md) — practise interview-style problem solving.
- [Code reviewer](code-reviewer.md) — review correctness, complexity, edge cases and code quality.

## How to use

1. Copy the prompt into the relevant existing ChatGPT conversation, or start a dedicated conversation.
2. Give the assistant your language, current topic and constraints if they are not already in the chat.
3. Ask it to start one question at a time.
4. Verify important claims with trusted references and tests.

**Context note:** a prompt can only use conversation history that is available to the model in that chat. If you start a new chat, paste your tracker or progress summary too. A prompt cannot independently send reminders or guarantee persistent memory across chats.
